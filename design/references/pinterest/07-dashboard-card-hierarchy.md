# Pattern 7 — Dashboard cards with strong visual hierarchy

**Concrete visual pattern:** a small set of large summary cards at the top (one number + one short plain-language label + a small trend or status chip each), then a "À traiter" list, then secondary charts. Key metrics are visually dominant; supporting detail is quieter. Cards use the same size and internal rhythm so staff scan them predictably, and each card has a one-click route to its underlying filtered list.

**Why it fits ACSF:** the dashboard must orient low-literacy staff in seconds. A large number with a short label is readable at 12px body type; consistent card anatomy supports recognition; drilling into the related table preserves context. Warm cream/yellow palette can be used as the card surface + accent without needing imagery.
